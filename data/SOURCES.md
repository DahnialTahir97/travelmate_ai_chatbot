# Dataset source verification log

The Q&A dataset is an original set of concise educational summaries written for this prototype. It contains no personal data.

The domain specialist must verify the factual answers against specific, current official pages and record:
- Q&A row or topic covered
- Exact source page URL (not only a homepage)
- Date accessed
- Any correction made to the answer

Starting points for research (not evidence that every answer is verified):
- Tourism Malaysia: https://www.malaysia.travel/
- Malaysia Immigration Department: https://www.imi.gov.my/
- Malaysian Meteorological Department: https://www.met.gov.my/
- Official attraction, transport operator and local authority pages.

Do not present TravelMate as a live or authoritative source for schedules, current prices, opening hours, weather or entry requirements.
